Site access

By default Image Downloader can only read a page after you click its toolbar icon (Chrome's activeTab permission). It asks for nothing at install and never scans anything in the background.

Because that access ends when you navigate or switch tabs, the side panel offers a one-time "Scan every page automatically" button. Accepting it grants access to all sites so the panel keeps up as you browse, and so image data can be read to convert or zip files. It is entirely optional and the extension works without it.

To undo it, right-click the toolbar icon and choose "This can read and change site data". Nothing is uploaded either way.

Privacy

Private by design — images never leave your browser. No account, no analytics, no backend, no remote code. Page URLs, image URLs and image contents are never sent anywhere.
