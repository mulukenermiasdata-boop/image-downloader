Image Downloader

Chrome extension

Find every image on a page, group the different sizes of the same picture together, and download the highest-quality original.

Get it on the Chrome Web Store

Why it exists

Most image downloaders list every image tag on a page, so you end up saving the 150-pixel thumbnail while the 2400-pixel original sits right there in the page source. Image Downloader looks at every version a page offers and picks the best one.

What it finds

  • Ordinary images, responsive srcset and <picture> sources
  • Lazy-loaded images and CSS background images
  • Inline SVG, and the full-size original linked behind a thumbnail
  • Open Graph images, and images added after the page finished loading
  • JPG, PNG, WebP, AVIF, GIF and SVG
Private by design. No account, no analytics, no servers, no remote code. Page addresses, image addresses and image data are never transmitted anywhere. Conversion and ZIP packaging run locally in your browser.

Permissions

Installing grants no access to your websites. The extension reads a page only after you click its toolbar icon. If you want the side panel to keep up as you browse, it offers a one-time optional button to grant access to all sites, which you can withdraw at any time by right-clicking the extension icon.
